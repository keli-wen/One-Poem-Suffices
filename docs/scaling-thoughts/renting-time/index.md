# Scaling 一下：出租时间与为自己工作

> 本文首发于知乎专栏 [Scaling 一下](https://www.zhihu.com/column/c_1869800540143226880)，2025-02-08

因为恰好回答了这个问题，想着改一改把自己的思考整理下，放到文章里来。我觉得杠杆和 scaling 有些共通性，本来想叫杠杆一下，但是最后还是叫这个名字吧。

大部分内容是直接复制过来的。我简陋地讲一讲自己的经历和想法。因为我还在"路上"，没有啥成功的经验，大家一听了之即可。若干年后再回头看可能觉得有点幼稚了。这篇文章也算是商业书籍读后感（《纳瓦尔宝典》），看看就好～

> "一旦品尝到自由的滋味，你就再也不想被别人雇用了。"

## 过往：一些出售时间的副业

在大学期间，我就开始做一些简单的副业，最开始是卖卖信用卡（扫楼），改一下论文降重到后来做一些课后作业辅导，再到后来因为一些朋友/前辈的信任从而介绍的外包。

老实来讲，对于其中绝大部分经历存在一些后悔，本质上我还是在出租时间，我换取的是金钱而非财富（关于财富的思考，我会在后文说到）。而且，学生阶段（本科）的时间杠杆最高，我本来应该花更多的时间在学习上。但是，回过头来反思的时候发现，正因为有这些经历才引起我后来的一些思考，所谓因果。而且，我也机缘巧合去了一个不太科研，但是组里氛围非常棒的组，最后也如愿去了 Google 实习，回头想这于我而言就是很完美的路径了。我认为所有人都拥有等值的财富是时间，我一些副业赚到了金钱，我用一些金钱来换取时间（包括但不限于，使用更快捷的交通工具，在生产力工具上进行更大的投入，所以我认为明智的支出也是一项技能，这并非倡导消费升级，有相关经验的兄弟自然懂）。所以，在很长一段时间，我是相信这个准则的："如果我出售时间换来的金钱可以为我购买更多时间，这是一笔划算的交易。"

## 反思：错误的为时间定价

讲到现在我貌似还在偏题中，请容我慢慢叙述。

我后续越来越觉得这并不是一笔划算交易的原因是：

- 我忽略了时间的机会成本。
- 我忽略了杠杆效应。
- 我忽略了为自己时间进行准确的定价。

我有许多前辈，我觉得我为数不多的能力就是尽量与比我当下更成功，更有经验的前辈（这里不是年龄意义上的）"交朋友"。很多人认为交朋友本质上是需要价值对等，无论是从当前价值的角度还是从未来价值的角度。所以，这也是一门学问，如果让我思考我自己为什么能有这样一些交朋友的机会，我可能会回答：自我驱动的能力（未来价值），靠谱的做成某事的能力（信任），各领域涉猎并广泛收集信息（未来价值）。

讲回来，我和他们进行了一些沟通，问出了大家可能也会问的一些问题。问题的答案我觉得都是"对"的，但是需要自己去体验的。其中一些我后来觉得挺有道理的：mgr 他的时间太值钱了，如果从零做一些诸如"独立开发者"的事情，对他来说不如休息，因为又浪费精力对比他的时薪来说又不值钱。

我这里不讲狭义的"独立开发"，我认为独立开发本质上就是创造你自己的"财富"，你为你自己打工。我对财富的理解和很多商业书籍的影响分不开，就是：能提供稳定的现金流，能产生"睡"后收入。比如一些能产生资本收入的固定资产，你的软件，你的博客，你的视频等等。

而且，任何事情都存在杠杆效应，我这里直接引用原书的内容吧：

!!! quote "《纳瓦尔宝典》— 三种杠杆"

    "第一种是**劳动力杠杆**，也就是让别人给你打工。"

    "资本是第二种相对较好的杠杆形式。**资本杠杆**就是用钱来扩大决策的影响力。"

    "最后一种杠杆是最新出现的，也是普通人最触手可及的。这种杠杆就是'**复制边际成本为零的产品**'。其中包括书籍、媒体、电影、代码。在所有不需要他人许可就能使用的杠杆中，代码可以说是最强大的一种——只需要一台计算机就够了。"

    "复制边际成本为零的产品是最值得研究的杠杆，也是最重要的杠杆。这是一种全新的杠杆形式，问世仅几百年。这种杠杆始于印刷机。广播媒体加速了其发展，而互联网和编程的出现更是使其产生了爆发式增长。不需要他人为你打工，也不需要他人给你投资，你就可以把劳动成果放大成百上千倍。"

    "新杠杆最重要的特点之一就是，使用它们或获得成功都无须经过他人的许可。要使用劳动力杠杆，就得有人决定追随你。要使用资本杠杆，就得有人给你提供资金，你再去进行投资或开发产品。而编程、写书、录播客、发推特、拍视频这些事情不需要经过任何人的许可。"

有些内容老生常谈，但是还是有些价值的，这所以有时候过于商业化而被人厌恶，本质上是有些扩大了它的作用范围。所以，我那时候做的副业有些短视，我还是在出售时间，并且做一些没有杠杆的事情（这决定了未来价值），我忽略了现在的时间其实和未来的时间一样值钱，那我本来就应该在最穷的时候（因为没工资 哈哈）去做一些能对未来有影响，有价值的事情。依靠出租时间是不可能致富的。

同样引用一句话："给自己的时间设定价格，用时薪计算时间价值。如果用花钱的方式节省的时间价值更高，那就花钱，不要犹豫。要想真的赚到钱，先要相信你自己很值钱。"

这就是为什么我觉得之前的副业不够划算。

## 解法：做带有杠杆的事？

那么，发现了问题，如何解决问题呢？哈哈，如果你也希望找到成功之道，这篇文章不会给你答案。成功路径不可复制，做自己更重要。所以我写我的思考，我的心路历程，只是希望给一些读者一些 inspiration。

我在前期就有 work for self 的想法，所以我一直希望进入一个外企，给自己一些时间，无论是身体健康或者做一些副业。在国内企业工作大部分情况下，需要出租自己的全部时间。所以在 LLM 与外企间，我选择了外企。外企当然在动荡之中，但凡事无法完美，尽人事。

有了这些前置工作，我便在思考自己可以从什么角度利用杠杆：

**1）劳动力杠杆**我觉得太低效了，我尝试在一些开源社区进行 minor project lead，我发现不如我自己写，想来我没有当 manager 的天赋。同时，在 AI 时代，我至少拥有四个勤劳的工人：ChatGPT/Claude/Gemini/DeepSeek，我自己 + 它们的效率可能高于我管理一个小 team。

**2）** 那么在 AI 时代下，个人效率完全可以通过 LLM scaling 起来，那么我认为 full stack && 独立开发会产生新的范式。

**3）** 技术在 LLM 发展下被平权了，除非你作为领头羊，否则你很难说自己能通过纯粹的技术"吃饭"。

**4）** 营销与流量是这个时代最重要的，无论是不是做软件，独立开发有时候时"粉丝经济"。

**5）** 所以个人影响力很重要，我得打造个人影响力，当时是被信任的个人影响力。

**6）** 资本的杠杆是很好用的，交易过的朋友都知道，百分比的效率太夸张了。

**7）** 但是我自己不确定是不是很擅长，但是我学习了基本的微观经济学/货币经济学等数据，我相信 LLM 会让我们学习效率倍增，但是在投资的方向上（资本杠杆），我是个纯纯的新手，但是过往经验告诉我，程序员的好处之一是快速实现原始积累后开始利用资本杠杆，我会和我周围在这个方向上擅长的人做好朋友。我自己也在做一些风险可控的投资，我认为交易市场对人的教育不亚于学校。同时，我之前学习的基础知识会让我在 LLM 时代不再惧怕一些复杂议题（我认为 LLM 时代下基本知识更重要，基本知识 + LLM ≈ 领域小专家）

**8）** 所以，我只剩第三种杠杆了，目前最优解肯定是视频作为载体（主流），但是我不确定我是否擅长。我比较热爱写博客，博客也是第三种杠杆，同时对个人品牌的打造有益。

**9）** 综上，劳动杠杆被我抛弃，资本杠杆我会持续学习但不会轻易使用，复制边际成本为零的产品，一种是 AI 时代下的全栈开发，另一种是偏传统的博客（但是我最近也在思考 LLM powered Blog Workflow，之后有可能会公布这篇思考），未来可能会涉猎一些视频相关的（虽然我觉得读文字摄入信息更快）。

!!! tip "一些建议"

    - 培养一个玩游戏外的爱好，最好是锻炼，否则娱乐和工作都是对着电脑屏幕。
    - 身体健康最重要，你不能在身体不舒服的时候才认为身体健康很重要。
    - 多阅读，AI 时代下信息是爆炸的，与其阅读别人加工后的信息，为什么不阅读原始信息呢？主动寻找信息，而非被动接收信息。

诸君共勉。
