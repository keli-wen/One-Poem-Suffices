# Scaling 一下：月供 $125，生产力能否随 Token 用量 Scaling？

> 原文发布于 [知乎想法](https://www.zhihu.com/pin/1994893951887495269)，2026-01-14

第一次充值了 Ultra/Max 版本的 AI 服务。Claude Max 5x，Apple Store 付费，125 usd 每月。

之前一直是 Codex / Claude Code / Cursor 一起用。但是发现主力还是 Claude Code。Codex 效果不错要等太久，Cursor 用完 20usd 后要被 routing 而且我觉得它更适合在我精调项目时使用，Claude Code Opus 4.5 兼具质量和速度，体验非常丝滑，就是 pro 会员用量太少。

在等了两次 5hour limit 后我决定充值一段时间 Max，看看效率能否随着 token 用量的 scaling 进一步 scaling？（这是一段时间前的观点，那段时间我疯狂用 AI 来进行自我对话，项目管理，健身/饮食/投资管理）并且正好赶上 Claude cowork 发布，正好还能体验下。
